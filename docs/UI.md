# 画面仕様

見た目と動きの正解は `web/demo.html`（デモ）です。本番の画面はデモと同じ見た目・同じ操作手順で作り、データだけを API から取ります。この文書はデモから読み取りにくい「決まりごと」をまとめたものです。

## 1. 方針

- **見やすさを最優先**。1画面に要点だけを置き、詳しい内容は1タップ先に置く。
- **最短で届く**。よく使う操作は「一覧の … メニュー」「サーバー詳細の上部ボタン」「検索」のどれかから **2タップ以内**で実行できること。
- デザインは Apple の iOS 27（Liquid Glass を読みやすく調整した世代）に合わせる：大きなタイトル、インセットのグループリスト、半透明のバー（ガラス）、下からのシート、丸い操作ボタン。
- 文言は日本語の敬体。ボタンは動詞で短く（「作成」「削除」「元に戻す」）。

## 2. デザインの値（CSS 変数。`web/css/tokens.css`）

| 用途 | ライト | ダーク |
|---|---|---|
| 背景 `--bg` | #F2F2F7 | #000000 |
| グループの背景 `--bg2` | #FFFFFF | #1C1C1E |
| 文字 `--label` / 補足 `--label2` | #000 / rgba(60,60,67,.6) | #FFF / rgba(235,235,245,.6) |
| 区切り線 `--sep` | rgba(60,60,67,.18) | rgba(84,84,88,.6) |
| 青（操作） | #007AFF | #0A84FF |
| 緑（正常） | #34C759 | #30D158 |
| 赤（停止・危険） | #FF3B30 | #FF453A |
| 橙（注意） | #FF9500 | #FF9F0A |
| 藍（メンテナンス） | #5856D6 | #5E5CE6 |

- 角の丸み：グループ 22px、タイル 18px、ヒーロー 26px、シート 32px、ボタン（カプセル）高さの半分。
- 文字：`-apple-system, "SF Pro Text", "Hiragino Sans", "Noto Sans JP"`。本文17px、補足14–15px、見出し（大きなタイトル）34px 太字。
- ガラス：`backdrop-filter: blur(24px) saturate(180%)`、背景は透明度 `--ga`（既定0.72）、0.5px の輪郭線。設定画面の「ガラスの透明度」で0.5〜0.97に変更でき、端末の「透明度を下げる」（`prefers-reduced-transparency`）では0.97にする。
- 押せる部品は最小44×44px。
- 背景：画面の一番下に固定の層（`#bg`）を置き、その上に地の色を「見やすさ」の割合で重ねる。`background-attachment: fixed` は iPhone で動かないので使わない。用意した背景はライトとダークで別の色（`BG_PRESETS`）。背景があるときは見出しに地の色の縁取り（`text-shadow`）を付ける。

## 3. 画面構成

### 3.1 ナビゲーション

- **スマホ（〜900px）**：下に浮いたタブバー（サーバー・監視・管理〈admin のみ〉・設定）、右下に独立した検索ボタン。
- **PC（901px〜）**：左にガラスのサイドバー。上から「検索」「タブ」「サーバーの一覧（状態の点つき）」「自分」。サーバー一覧から1クリックで詳細へ。
- 画面の上は「戻る」「タイトル（スクロールすると表示）」「右側の操作」のナビゲーションバー。スクロールするとガラスになる。
- 画面の遷移は「タブ ＋ 積み重ね（スタック）」。URL にも反映する（`/servers/storia/backups` など）。ブラウザの戻るで1つ戻る。

### 3.2A 画面サイズごとの配置

| 条件 | 配置 |
|---|---|
| 幅1100px〜 | サイドバー300px |
| 幅700〜1099px（フォルダブルを開いた状態・タブレット） | サイドバー248px、本文の左右余白20px |
| 幅〜699px（スマホ・フォルダブルを開いた縦持ち） | 下のタブバー、右下に検索ボタン。本文の左右余白16px（safe area を考慮） |
| 幅〜359px（カバー画面など） | 余白12px、見出し28px、タイル・ボタン・入力欄を詰める。タブ幅52px |
| 高さ〜500px の横向き | 見出し26px、シートは画面の高さいっぱい |
| `horizontal-viewport-segments: 2` | 左の画面にサイドバー、右の画面に本文とシート（折り目の幅だけ余白） |
| `vertical-viewport-segments: 2` | シートは下の画面に出す |

- タイルの列数は画面幅ではなく **本文の幅**（コンテナクエリ）で決める：600px 以上で4列、それ未満は2列。
- 高さは `dvh`、`<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover, interactive-widget=resizes-content">`。
- 確認する幅（Playwright）：320×640、344×882（カバー画面）、390×844、430×932、673×841（開いた縦持ち）、884×1104、844×390（横向き）、1024×768、1280×800。すべてで横スクロールが出ないこと。

### 3.3 シート（下から出る画面）

- 新しいサーバー（3段階：種類 → 名前・プラン・アドレス → 確認）
- アドレス枠の追加・編集（入力するたびにプレビューと検証を更新）
- 確認（削除など）。**元に戻せない操作は名前の入力で確認**（完全に削除・退会）
- 検索、各種の追加（ドメイン・IP・紐付け・ユーザー・お知らせ・違反）
- ヘッダーは「左：キャンセル／戻る」「中央：タイトル」「右：主な操作（太字）」。条件を満たさないときは右の操作を無効にする。
- スマホでは画面の下端に張り付き、上端に掴み線を表示。PC では中央に表示。

## 4. 動きの決まり

- **検索**：`/` キーまたは Ctrl/⌘+K で開く。サーバー名・アドレス・ポート番号・所有者・画面名・（admin）ユーザー名とアドレスを検索。Enter で最初の結果へ。
- **作成画面のアドレス選択**：固定ホスト名の枠（例 mcNNtrt.nuids.jp）を先に、`{server}` の枠を後に出し、最初の空きを初期選択にする。名前を入力すると `{server}` の選択肢の表示もその場で変わる。
- **アドレス枠の編集**：入力のたびに `POST /api/admin/slot-rules/preview` を300ms 間引きで呼び、プレビュー（最大40行）と問題点を表示。問題があると保存できない。新規作成の初期値は既存の枠と重ならない範囲と、`開始番号 = 開始ポートの下2桁`。
- **ジョブの進捗**：一覧の上のバナーと、該当サーバーの行に現在の手順を表示。完了したら「開く」ボタン。失敗したら赤いバナー（「すべて取り消しました」）。入力中やシート表示中は画面全体を描き直さない（入力が消えるため）。完了時の描き直しはシートを閉じた後に行う。
- **トースト**：画面上部に丸いガラスの通知を2.6秒。成功は緑のチェック、注意は橙。
- **空の状態**：一覧が空のときは、次に何をすればよいかを1文で書く（「右上の＋から作成できます」）。
- **エラー**：API の `message` をそのまま表示。入力欄のエラーは欄の下に赤字で。

## 5. アクセシビリティ

- すべての操作はキーボードで実行できる。フォーカスは青い輪で表示。Esc でシート・メニューを閉じ、詳細画面では1つ戻る。
- **選択肢（select の代わり）**：ブラウザ標準のプルダウンは使わない（OS の白いリストになり、ダークモードや背景と合わないため）。行の右に「今の値 ＋ ⇅」のボタンを置き、押すと … メニューと同じガラスの一覧（`web/js/components/picker.js`）が開く。選択中の項目は青字とチェック。補足の説明を2行目に出せる。↑↓で移動、Enter・Space で決定、Esc で閉じる。画面の端では上に開き、長い一覧は中でスクロールする。
- **… メニュー**：一覧の各行の「…」とナビゲーションバーの「…」は、同じガラスの一覧（`openMenu`）で操作を出す。危険な操作（削除）は区切り線の下に赤字で置く。
- **画面のファイル**：`web/js/pages/servers.js`（サーバー）、`pages/admin-address.js`（管理とアドレス）、`pages/jobs.js`（ジョブの進捗）。各画面は API を読んでから描く（遅いときだけ「読み込んでいます」）。
- アイコンだけのボタンには `aria-label`。状態は色だけで伝えない（文字も併記：「稼働中」「応答なし」）。
- `prefers-reduced-motion` ではアニメーションを止める。
- 文字の拡大（200%）でも横スクロールが出ないこと。

## 6. 実装上の注意

- **グローバル変数に `top`、`name`、`status`、`parent`、`length`、`origin` などを使わない**（ブラウザの `window` のプロパティと衝突して画面が真っ白になる。デモ作成時に実際に起きた）。モジュール（`type="module"`）で書けば起きない。
- 描画は文字列テンプレートでよいが、**利用者が入力した値は必ずエスケープ**（デモの `esc()`）。
- 画面の状態（選択中のタブ、スタック）は URL が正本。再読み込みしても同じ画面に戻ること。
